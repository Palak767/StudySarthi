# StudySarthi

StudySarthi is a responsive student productivity platform designed to help students manage academics, coding practice, internships, and career goals from one dashboard.

## Features

- Responsive Landing Page
- Dashboard
- Goal Tracking
- Progress Analytics
- FAQ Accordion
- Animated Statistics
- Contact Form
- Mobile Navigation

## Technologies

- HTML5
- CSS3
- JavaScript
- Flexbox
- CSS Grid
